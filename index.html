Principais Comandos Git

  • git init Inicializa o repositório na pasta atual
  • git clone [url] Baixa um repositório remoto existente
  • git status Exibe o estado das suas alterações
  • git add . Adiciona arquivos para a fila de envio
  • git commit -m "msg" Salva um histórico com mensagem explicativa
  • git push origin main Envia alterações salvas para o GitHub
